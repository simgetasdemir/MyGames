# Arka plan müziği

Bu klasöre `arka-plan.mp3` adında bir müzik dosyası konursa oyun onu arka planda döngüde çalar.
Dosya yoksa oyunun kendi bestelenmiş müziği çalar.

Atıf metni `shared/data.js` içindeki `MUSIC.credit` alanındadır ve oyunun altında gösterilir.
Farklı bir parça kullanırsanız bu metni o parçanın lisansına göre güncelleyin.
